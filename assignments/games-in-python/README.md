# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a playable Hangman game in Python that uses strings, loops, conditionals, and user input to create a fun word-guessing experience.

## 📝 Tasks

### 🛠️ Task 1: Create the Game Logic

#### Description
Write a Python program that selects a hidden word, lets the player guess letters, and updates the display as they progress.

#### Requirements
Completed program should:

- Choose a random word from a predefined list of words
- Show the current progress using underscores or blanks for unrevealed letters
- Accept single-letter guesses from the player
- Reveal correctly guessed letters in the hidden word
- Track and display how many lives or attempts remain
- End the game when the player wins or runs out of attempts

### 🛠️ Task 2: Add Game Feedback and End Conditions

#### Description
Improve the game so it feels polished and clearly communicates the outcome to the player.

#### Requirements
Completed program should:

- Display a message when a letter is already guessed
- Show a message when a guess is incorrect
- Keep track of guessed letters so the player does not repeat guesses
- Print a final win or lose message at the end of the game
- Include simple input/output formatting that is easy to follow and play
