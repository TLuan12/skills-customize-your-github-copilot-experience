# 📘 Assignment: Data Cleaning and Summary Report

## 🎯 Objective

Practice cleaning a messy dataset and summarizing the results with Python by transforming raw records into meaningful insights.

## 📝 Tasks

### 🛠️ Task 1: Load and Inspect the Data

#### Description
Read the provided CSV file and inspect the structure so you can identify missing or inconsistent values before analysis.

#### Requirements
Completed program should:

- Read the CSV file using Python
- Display the first several rows so the dataset can be inspected
- Identify columns that may need cleaning, such as missing values or inconsistent capitalization
- Print the total number of rows in the dataset

### 🛠️ Task 2: Clean the Data

#### Description
Fix common data quality issues so the dataset is easier to analyze and summarize accurately.

#### Requirements
Completed program should:

- Replace or remove missing values where appropriate
- Standardize inconsistent text values, such as capitalization differences
- Convert numeric values to the correct type when needed
- Remove duplicate rows if they are present
- Keep a cleaned version of the dataset for use in the summary

### 🛠️ Task 3: Calculate Summary Statistics

#### Description
Use the cleaned dataset to compute a few simple statistics that help describe the information in the file.

#### Requirements
Completed program should:

- Calculate the total number of records after cleaning
- Find the average, minimum, and maximum value for a numeric column
- Count how many values fall into each category for a text column
- Print the results in a clear and readable format

### 🛠️ Task 4: Write a Short Report

#### Description
Summarize the key findings from the cleaned dataset in a short written report.

#### Requirements
Completed program should:

- Explain what the dataset is about in 1-2 sentences
- Mention the main cleaning steps that were performed
- Include 2-3 interesting observations from the summary statistics
- Present the final results in a clean, readable format suitable for a class report
